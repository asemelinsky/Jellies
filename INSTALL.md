# Як встановити «Желейки»

Програма не потребує інсталятора, прав адміністратора чи інтернету після скачування. Нижче покроково описано, як поставити її на Windows і на Linux, зробити ярлик, перевірити швидкодію та видалити.

**Вимоги до комп'ютера**

| | Мінімум | Для 60 FPS із 50 желейками (1920×1080) |
| --- | --- | --- |
| Система | Windows 10/11 64-bit або Linux x86-64 | те саме |
| Відеокарта | будь-яка з підтримкою OpenGL 3.3 | GeForce GTX 1050, Intel Iris Xe або краща |
| Процесор | будь-який 64-бітний | 4 ядра, не старший за ~2016 рік |
| Пам'ять | 4 ГБ | 8 ГБ |
| Місце на диску | ~5 МБ | ~5 МБ |

---

## Windows 10 / 11

### 1. Скачати

Відкрийте посилання: **[Jellies-Windows-x64.exe](https://github.com/asemelinsky/Jellies/releases/latest/download/Jellies-Windows-x64.exe)**.

Браузер може попередити, що файл «завантажують нечасто». Це нормально для нової програми без платного цифрового підпису:
- **Edge:** наведіть на завантаження → «…» → «Зберегти» → «Показати більше» → «Усе одно зберегти»;
- **Chrome:** «Зберегти» або «Усе одно завантажити».

### 2. Покласти в постійну папку

Створіть папку, наприклад `C:\Games\Jellies` або `Документи\Желейки`, і перемістіть туди `Jellies-Windows-x64.exe` з «Завантажень». Більше нічого не потрібно: увесь код, шрифт і звуки вже всередині файлу.

### 3. Перший запуск

Двічі клацніть по файлу. Якщо з'явиться синє вікно **«Windows захистив ваш ПК»** (SmartScreen):
1. натисніть **«Докладніше»**;
2. натисніть **«Виконати в будь-якому разі»**.

Це питання з'являється лише при першому запуску.

### 4. Ярлик на робочий стіл (за бажанням)

1. Клацніть правою кнопкою по `Jellies-Windows-x64.exe`.
2. У Windows 11 оберіть **«Показати додаткові параметри»**.
3. **«Надіслати»** → **«Робочий стіл (створити ярлик)»**.

Щоб програма одразу відкривалась на весь екран: правою кнопкою по ярлику → **«Властивості»** → у полі **«Об'єкт»** допишіть після лапок пробіл і `--fullscreen`:

```
"C:\Games\Jellies\Jellies-Windows-x64.exe" --fullscreen
```

### 5. Ноутбук із двома відеокартами

Якщо в ноутбуці є і вбудована графіка Intel/AMD, і окрема NVIDIA/AMD, змусьте програму працювати на потужнішій:
**Параметри → Система → Дисплей → Графіка** → «Додати програму» / «Огляд» → оберіть `Jellies-Windows-x64.exe` → **«Параметри»** → **«Висока продуктивність»** → «Зберегти».

### 6. Видалення

Просто видаліть файл `.exe` (і ярлик, якщо створювали). Програма нічого не пише в реєстр і не встановлює служб. Якщо запускали тест швидкодії, поруч може лежати файл `jellies_benchmark.txt`.

### Якщо щось не так (Windows)

| Проблема | Що зробити |
| --- | --- |
| Вікно не відкривається або одразу закривається | Оновіть драйвер відеокарти з сайту NVIDIA, AMD чи Intel. Потрібна підтримка OpenGL 3.3 |
| Антивірус видалив або заблокував файл | Це хибне спрацювання на непідписаний `.exe`. Додайте файл у винятки антивірусу або скачайте ще раз |
| Низький FPS | У панелі змініть «Тіні» на «Середня» чи «Низька»; на ноутбуці див. пункт 5 |
| Немає звуку | Натисніть **M**: звук міг бути вимкнений |

## Linux

Підходить для 64-бітних дистрибутивів, не старших за **Ubuntu 22.04**: Ubuntu 22.04+, Linux Mint 21+, Debian 12+, Fedora 36+, Arch, Manjaro тощо. Працює і в X11, і у Wayland (через XWayland, який є в усіх популярних робочих столах).

### 1. Скачати й розпакувати

Через браузер: **[Jellies-Linux-x64.tar.gz](https://github.com/asemelinsky/Jellies/releases/latest/download/Jellies-Linux-x64.tar.gz)**, далі розпакуйте архів подвійним клацанням або в терміналі.

Або повністю в терміналі:

```sh
cd ~/Downloads        # або ~/Завантаження
wget https://github.com/asemelinsky/Jellies/releases/latest/download/Jellies-Linux-x64.tar.gz
tar xzf Jellies-Linux-x64.tar.gz
cd Jellies
```

### 2. Спробувати без встановлення

```sh
./jellies
```

На весь екран: `./jellies --fullscreen`.

### 3. Встановити в меню програм (за бажанням)

```sh
./install.sh
```

Скрипт **не потребує sudo**. Він копіює програму в `~/.local/share/jellies`, додає команду `jellies` у `~/.local/bin` і пункт **«Желейки»** з іконкою в меню застосунків. Після цього програму можна шукати в меню, як будь-яку іншу.

Якщо скрипт повідомить, що `~/.local/bin` немає в `PATH`, команда `jellies` у терміналі запрацює після повторного входу в систему. Пункт у меню працює одразу.

### 4. Видалення

```sh
~/.local/share/jellies/uninstall.sh
```

Або, якщо не встановлювали, просто видаліть розпаковану папку `Jellies`.

### Якщо щось не так (Linux)

Майже на всіх дистрибутивах із графічним робочим столом потрібні бібліотеки вже встановлені. Якщо програма пише, що не може відкрити вікно або OpenGL, доставте їх:

```sh
# Ubuntu / Mint / Debian
sudo apt install libgl1 libx11-6 libxrandr2 libxinerama1 libxcursor1 libxi6
# Fedora
sudo dnf install mesa-libGL libX11 libXrandr libXinerama libXcursor libXi
# Arch / Manjaro
sudo pacman -S mesa libx11 libxrandr libxinerama libxcursor libxi
```

| Проблема | Що зробити |
| --- | --- |
| `Permission denied` при запуску | `chmod +x jellies install.sh uninstall.sh` |
| `GLIBC_2.35 not found` | Дистрибутив застарий. Оновіться до Ubuntu 22.04+ чи аналога або зберіть програму з коду (див. README) |
| Помилка OpenGL / чорне вікно | Оновіть драйвери. Для NVIDIA встановіть пропрієтарний драйвер; для Intel/AMD підійде Mesa 21 і новіша |
| Віртуальна машина без 3D | Увімкніть 3D-прискорення у VM або запустіть повільний програмний режим: `LIBGL_ALWAYS_SOFTWARE=1 ./jellies` |
| Немає звуку | Потрібен PulseAudio, PipeWire або ALSA (є в будь-якому робочому столі). Також перевірте клавішу **M** |

## Перевірка швидкодії (обидві системи)

Запустіть програму з параметром `--bench`:

- **Windows:** створіть ярлик (пункт 4), у полі «Об'єкт» допишіть ` --bench`, запустіть ярлик;
- **Linux:** `./jellies --bench` (або `jellies --bench`, якщо встановили).

Програма відкриється на весь екран, за 5 секунд насипле 50 желейок і 20 секунд вимірюватиме швидкість із вимкненою вертикальною синхронізацією. Результат з'явиться на екрані й збережеться у файл `jellies_benchmark.txt` у робочій папці: поруч з `.exe` на Windows, у поточній папці терміналу на Linux. Вимога ТЗ виконана, якщо **«1% low» не нижче 60 FPS** при тінях «Висока» в роздільності 1920×1080. Закрити програму: Alt+F4.
