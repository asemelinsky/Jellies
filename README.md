# Желейки

3D-симуляція м'яких тіл на C++. На нерухому платформу падають напівпрозорі желейки: кубики, кульки, ведмедики, черв'ячки, сердечка, зірочки, циліндри й пірамідки всіх кольорів веселки. Вони сплющуються від ударів, тремтять, відскакують і налипають одна на одну. Желейку можна схопити мишею й кинути. Сонце саме сходить і заходить, тож змінюються тіні й колір неба, а на просвіт желе світиться зсередини.

| Система | Файл |
| --- | --- |
| **Windows 10/11 (64-bit)** | [⬇ Jellies-Windows-x64.exe](https://github.com/asemelinsky/Jellies/releases/latest/download/Jellies-Windows-x64.exe) |
| **Linux (x86-64)** | [⬇ Jellies-Linux-x64.tar.gz](https://github.com/asemelinsky/Jellies/releases/latest/download/Jellies-Linux-x64.tar.gz) |

**Грати в браузері** без встановлення: **https://asemelinsky.github.io/Jellies/**. Потрібен браузер із WebGL 2. Для найкращої швидкодії (особливо з 50 желейками) радимо версію для комп'ютера.

**Windows:** скачайте файл і запустіть. Інсталяція не потрібна, програма працює офлайн. Файл не підписаний, тому Windows може показати «Windows захистив ваш ПК»: натисніть «Докладніше», потім «Виконати в будь-якому разі».

**Linux:**

```sh
tar xzf Jellies-Linux-x64.tar.gz
cd Jellies
./jellies          # запуск без встановлення
./install.sh       # за бажанням: додати в меню програм (без sudo)
```

Потрібна відеокарта з підтримкою OpenGL 3.3 і встановлені драйвери (Mesa, NVIDIA або AMD).

Збірки оновлюються автоматично після кожної зміни коду. Усі файли є на [сторінці релізу](https://github.com/asemelinsky/Jellies/releases/latest).

**Докладна інструкція зі встановлення** для Windows і Linux (ярлик, меню програм, видалення, вирішення проблем, тест швидкодії): [INSTALL.md](INSTALL.md).

## Керування

| Дія | Клавіша / миша |
| --- | --- |
| Схопити й кинути желейку | Ліва кнопка миші (кидок — відпустити в русі) |
| Обертати камеру | Права кнопка миші |
| Наближення / віддалення | Коліщатко миші |
| Нова желейка | Пробіл |
| 10 желейок одразу | Shift + Пробіл |
| Пауза | P |
| Скинути сцену | R |
| Сховати / показати панель | H |
| Увімкнути / вимкнути звук | M |
| Повний екран | F11 |
| Вертикальна синхронізація | V |

Нова желейка з'являється автоматично кожні 10 секунд.

**Панель у куті екрана:**
- кнопки «Пауза» та «Скинути сцену»;
- повзунки «Швидкість часу», «Гравітація», «М'якість желе» та «Липкість»;
- перемикач якості тіней: низька, середня, висока, ультра;
- лічильник FPS.

**Параметри запуску:**
- `--fullscreen` відкриває програму одразу на весь екран, наприклад `Jellies-Windows-x64.exe --fullscreen`;
- `--bench` запускає тест швидкодії: 50 желейок, вимірювання 20 секунд, результат (середній FPS, 1% low, p95) на екрані та у файлі `jellies_benchmark.txt`.

## Збірка з вихідного коду

Що потрібно:
- CMake 3.16 або новіший;
- компілятор C++17: MSVC 2022, MinGW-w64, GCC або Clang;
- git. Бібліотека raylib 5.5 завантажується автоматично під час збірки.

**Windows (Visual Studio 2022):**

```sh
cmake -B build -A x64
cmake --build build --config Release
```

Результат: `build/Release/Jelly.exe`.

**Linux:**

```sh
sudo apt install build-essential cmake git libx11-dev libxrandr-dev libxinerama-dev \
                 libxcursor-dev libxi-dev libgl1-mesa-dev
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
./build/jelly
```

**Збірка для Windows на Linux (MinGW-w64):**

```sh
cmake -B build-win -DCMAKE_TOOLCHAIN_FILE=cmake/mingw-w64-x86_64.cmake
cmake --build build-win -j
```

Щоб зібрати без інтернету, вкажіть локальну копію raylib: `-DFETCHCONTENT_SOURCE_DIR_RAYLIB=/шлях/до/raylib-5.5`.

**Веб-версія (WebAssembly, потрібен [Emscripten](https://emscripten.org) 3.1.74):**

```sh
emcmake cmake -B build-web -DCMAKE_BUILD_TYPE=Release
cmake --build build-web -j
cd build-web && python3 -m http.server 8000   # відкрийте http://localhost:8000/jellies.html
```

Після кожного push у `main` GitHub Actions збирає версії для Windows (MSVC) і Linux, оновлює реліз `latest` і публікує веб-версію на GitHub Pages.

## Як це працює

- **Фізика м'яких тіл.** Використано Position-Based Dynamics із shape matching: кожна желейка складається з частинок, згрупованих у кластери, що перекриваються, плюс один глобальний кластер. Крок симуляції ділиться на підкроки, швидкість частинок обмежена, а внутрішнє згасання гасить коливання. Так желе тремтить і повертає форму, а швидкі кидки не пролітають крізь об'єкти.
- **Зіткнення.** Просторова хеш-сітка швидко знаходить пари желейок, що торкаються (broad phase), а потім перевіряються лише частинки в зоні їхнього контакту (narrow phase). Платформа є коробкою з тертям, тож із її країв можна впасти.
- **Ефекти.** Кольорові каустики (світло, сфокусоване желе, малює яскраві плями на платформі), очі у ведмедиків і черв'ячків, що тремтять і кліпають, бризки при сильних ударах і мокрі сліди, які поступово висихають, а також короткочасне злипання желейок.
- **Форми.** Усі 8 форм генеруються кодом із неявних поверхонь (SDF). Частинки розміщуються на решітці всередині поверхні. Сітка для рендеру будується методом surface nets і деформується разом із частинками.
- **Миша.** Із курсора пускається промінь, і захоплюється найближча до камери желейка. Її тягне до курсора «пружина», а швидкість кидка обмежена.
- **Графіка.** Тіні будуються через shadow mapping із м'якою фільтрацією PCF. Окрема кольорова карта тіней дає напівпрозорі кольорові тіні від желе. Заломлення фону робиться в екранному просторі, відблиски — ефектом Френеля, а світіння на просвіт — імітацією підповерхневого розсіювання. Цикл дня й ночі змінює колір неба та світла.
- **Звук.** Шльопання й «чвакання» синтезуються кодом. Гучність обмежена, а часті повтори приглушуються.

Через обмеження реального часу заломлення й проходження світла крізь желе є візуальною апроксимацією, а не трасуванням променів. Желейка, яку видно крізь іншу желейку, не отримує подвійного викривлення.

## Ліцензії сторонніх компонентів

- [raylib](https://github.com/raysan5/raylib) розповсюджується за ліцензією zlib/libpng.
- Шрифт DejaVu Sans Bold вбудовано в програму як підмножину з латиницею й кирилицею. Він розповсюджується за ліцензією Bitstream Vera / DejaVu, яка дозволяє вільно використовувати й вбудовувати шрифт.
